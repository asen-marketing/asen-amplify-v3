# Asen Amplify (v3)

Asen Marketing's WordPress theme for client sites. Successor to [amplify-lite](https://github.com/asen-marketing/amplify-lite), which stays frozen for the sites already built on it.

v3 is a **parent theme**: each client site is a child theme in its own repo, and the parent updates itself from GitHub releases (see MODERNIZATION.md, Phase 5).

- Conventions and architecture: [AGENTS.md](AGENTS.md)
- Roadmap and decisions: [MODERNIZATION.md](MODERNIZATION.md)
- Requires WordPress 6.7+, PHP 8.1+, ACF Pro, ACF Extended, WP-SCSS.
